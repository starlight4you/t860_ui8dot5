# v1.0.1 A102 升级安装器修正 · 2026-10-13

从 v0.48.1 升级请使用 **Upgrade-TWRP-v1.0.1-A102.7z.001–003**。它替代 A100 升级包；全新安装仍使用原 A100 Odin 包。

修复 A100 内置模块检查工具与安装器参数不匹配，导致来源校验通过后仍报“Pending or unsafe system module state”。换入支持升级预检和保留原文件备份的工具，增加模块目录不可读时的提前提示，并直接显示模块检查的具体错误。

SYSTEM/PRODUCT 镜像、内核和 VENDOR 修正内容不变。保留设备、来源和待激活更新检查，不格式化 DATA，不清空应用、账户或锁屏信息。验证包括原版 Recovery 工具环境中的 67 项模块检查、9 项访问检查，以及完整包 114 个载荷块和 21 个辅助文件。

1. 下载 A102 三个分卷及 `SHA256SUMS-A102`，放到同一文件夹；核对摘要。
2. 用 7-Zip 打开 `.001` 并解压，得到 `TabS6-OneUI8.5-v1.0.1-A102-Upgrade-TWRP.zip`。不要把分卷直接交给 TWRP。
3. 将解出的 ZIP 放到 SD 卡或使用 ADB sideload；在 TWRP 中安装 ZIP。此 TWRP 无法解密内部存储，请不要为此格式化 DATA。
4. 安装成功后手动重启系统。若仍失败，请保存现在显示的具体模块报错；不要强行绕过会话检查。

`TabS6-Upgrade-Check-A102.zip` 是可选的只读检查包，不安装 ROM；从 SD 卡运行即可对比旧/新版模块工具结果，并显示目录是否可读。

充电复测：本次充电头 15%→65% 用时约69分钟，持续 PDIC/Fast/HV1，最高31.4°C；电池容量仍为7040mAh。
